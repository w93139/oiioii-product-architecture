1. 执行摘要

一句话架构：OiiOii 是一个以“聊天 + 可视画布”为工作台、由专业 Agent 串行推进、通过用户确认门逐阶段生成剧本—角色—场景—道具—分镜—视频资产的异步创作系统；当前页面已经暴露出状态事实源分裂、最终完成定义不清和资产依赖治理不足。

当前已确认

多 Agent 身份、阶段确认、画布资产图、模型选项、分镜视频生成、预览/剪辑/下载入口、任务与错误提示。

核心合理推断

存在项目上下文、Agent 编排、异步工具调用、模型调用、媒资保存与有向依赖，但后台实现和字段 schema 不可见。

关键建议

建立统一状态事实源、版本化资产 DAG、质量与完成门、幂等重试、额度冻结、权限隔离和全链路追踪。

1 进入项目输入现代言情故事；可选 3D言情。艺术总监首次接管；Oii Agent 作为统一容器。激活工作流、更新短片参数完成卡。写入原始需求、项目/工作流状态、参数草案（字段为推断）。暂无创意资产。需要确认影片基本信息；失败路径未知。
2 剧本查看“我的剧本”；满意继续或修改。编剧围绕“觉醒”生成 0-1 剧本。检索剧本知识（具体调用推断）；生成剧本资产。写入 script.current 与确认状态（推断）。1 个剧本卡。不满意→修改→再确认；版本未知。
3 角色查看 3 个图片；满意/修改提示词。角色设计师读取角色/外貌/风格。生成角色主图；更新提示词入口。写入角色列表、提示词、主图引用（schema推断）。许清和、顾砚、江叙白主图。不满意→局部重生（路径入口已确认，执行未演示）。
4 场景/道具发送“生成道具”。场景设计师先检查依赖；缺多视图则阻断。检查多视图；补生成场景；提取/生成道具（执行者部分推断）。更新 scene.multiview_status；写入 props（推断）。1 个 3 图场景卡、3 个道具卡。场景缺失→停止→补齐→确认→继续。
5 分镜方案选择 Seedance 2.0、Pro/Fast、720p/480p；不要分镜图；先1个/全部。道具设计师明确邀请分镜师；分镜师提取 4 镜头。检索运镜知识（调用形态推断）；生成画面/音效/台词提示词。读取上游资产；写 storyboard[1..4] 与模型配置（推断）。4 个镜头/提示词卡。提示词满意→小样/批量；不满意修改。

7 视频批量等待镜头2/3/4；查看“3个视频”。分镜师再次执行。并行或批量生成 3 视频（并行方式未知）。写 video[2..4]；任务状态变“当前无任务”。最终画布 4 个视频卡。生成失败/余额不足/中断无真实分支证据。
8 最终预览预览最终视频/去剪辑/下载所有分镜。无独立 Agent 身份；最终界面预检。预览预检；剪辑/下载仅入口。读取视频及音效/BGM完整性。视频存在；音效/BGM不完整。警告→取消或确定；最终合成未确认。
9 状态冲突仍看到“满意吗”。聊天逻辑仍待确认。无工具在运行。任务面板“当前无任务”；资产页为空；画布有资产。同一项目的资产在不同视图口径不一致。建议进入 reconciliation_required，当前产品未见。

项目临时数据需求、剧本、角色、场景、道具、分镜、视频、确认状态。项目数据已确认版本化上下文 + 资产 lineage + retention policy。
反馈/模型表现满意/修改按钮与用户消息。项目反馈；是否沉淀未知当前项目反馈已确认默认只影响项目；用于全局训练/评测必须单独同意并脱敏。

七个关键问题

1 风格如何可执行？【已确认】用户选 3D言情；【未知】编译方式。建议 StyleProfile → 模型适配器 → 提示词/参数/校验规则。
2 角色如何跨分镜复用？【已确认】角色卡和画布连线；【未知】稳定引用。建议每镜头引用 CharacterAssetVersion/FaceID，而非复制描述。
3 镜头知识来自哪里？【已确认】分镜师公开摘要称检索“觉醒”运镜知识；具体知识库和条目未知。
4 模型能力如何知道？【已确认】UI 展示 Seedance 选项与约束；【合理推断】存在配置；建议能力注册表驱动 UI 与调用校验。
5 安全与计费放哪里？【建议设计】必须由工具/模型网关强制；Agent Prompt 只能辅助，不是唯一防线。
6 用户反馈是否沉淀？【已确认】只看到当前项目确认；【未知】是否学习。建议默认项目级，平台学习需 opt-in。
7 私有/公共如何隔离？【未知】当前实现；建议租户 ACL、对象存储前缀、检索过滤、审计日志与最小授权。

16. 关键风险

P0

状态事实源分裂

聊天待确认、任务无任务、画布有资产、资产侧栏为空。可能导致错误交接、误删或误完成。

P0

口头完成替代真实完成

“规划完成/已生成”可能早于状态、资产、音频或最终合成完成。

P0

资产成功但上下文未更新

生成工具成功若写入失败，画布/侧栏/下游读取可能分叉。

P0

用户中断后继续执行

长视频任务若无取消令牌，后台可能继续扣费并生成晚到资产。

P0

私有资产权限泄漏

角色参考图、FaceID、音色属于高敏私有资产；隔离机制不可见。

P1

上游修改未使下游失效

角色/场景改版后旧分镜和视频仍可能被当作当前结果。

P1

自动重试重复扣费

无幂等和账本冻结证据；重复请求可能产生多资产/多账单。

P1

时长偏离原剧本

影片长度值与镜头时长校验不可见，最终视频可能严重偏离目标。

P1

风格一致性缺失

3D言情选择是否贯穿角色/场景/道具/视频与校验不可确认。

P1

台词与音画同步缺失

音效/BGM未完整，未见台词时长与嘴型/画面同步验证。

P2

安全误判/解释不足

未见安全实例；缺少规则版本和申诉可能导致无法解释拦截。

P2

知识与模型能力过期

知识/模型限制若无版本更新，会让 Prompt、UI 与实际能力漂移。

18. 仍然无法确认的问题

主控与编排

Oii Agent 是独立主控、群聊容器还是 UI 名称；专业 Agent 如何调度、恢复和重入。

后台技术栈

前端框架、服务语言、数据库、对象存储、CDN、队列、工作流引擎和云服务。

模型目录

文本/图片/音频模型名，Seedance之外是否有路由、降级、回退、健康度与价格。

资产引用

角色/场景/道具是否通过稳定 ID、URI、Face ID、embedding、名称代称或提示词复制关联分镜。

历史与失效

是否有 AssetVersion、项目历史、局部回退；上游修改如何使下游失效。

任务语义

“当前无任务”是否只代表没有后台作业，还是阶段完成；聊天满意门如何同步。

计费

STAR 与模型调用的换算、估价、冻结、扣费、退款、失败/重试费用和会员权益。

安全与版权

输入/输出审核、规则版本、真人/肖像/音色许可、误判恢复和审计。

音频链

音效、BGM、台词、音色、TTS、视频原生音频的生产者与完成条件。

发布/剪辑

剪辑器是否内置、最终合成与导出格式、发布渠道、权限和可恢复性。

用户数据隔离

私有资产的租户边界、跨项目复用授权、下载链接权限、数据保留与删除。

质量与效果
