# OiiOii 产品架构拆解

一份静态 HTML 产品研究报告，整理功能域、用户流程、Agent 与工具关系、上下文与资产架构、数据实体和风险。报告在页面中区分界面证据、推断、尚未确认的问题与建议架构。

## 阅读

入口为 [index.html](index.html)，配图位于 [OiiOii-拆解图片汇总/](OiiOii-拆解图片汇总/)。本地预览需要 Python 3：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000/>，无需安装依赖或构建。

## 证据范围

这是第三方产品研究，并非 OiiOii 官方文档。报告引用 18 张原始操作截图，当前仓库仅附其中 3 张示例，其余截图未随仓库提供；不能仅凭本仓库复核全部原始证据。

所述架构基于报告列出的可见证据，不能当作已取得服务端源码或内部部署事实；建议架构也不表示产品已经采用。证据缺口与未确认事项见报告第 2、18 节。图表从 jsDelivr 加载 Mermaid 渲染库，显示图表需要网络连接。

仓库未声明统一开源许可证；产品名称和界面素材的权利归相应权利人所有。
